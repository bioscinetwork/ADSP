# ADSP Structural Data Repository

This directory organizes standard structural inputs and reference ligands used for docking studies and validation.

## Organization

- 
eceptors/: Destination for target macromolecule PDB/mmCIF structures and pre-prepared PDBQT files.
- ligands/: Destination for candidate compound libraries, SDF files, and prepared ligand PDBQT files.
- 
eference/: Curated reference ligand conformations (ADP, HRM, Donepezil) for docking validation.
